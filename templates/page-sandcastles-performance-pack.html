Quick Installation (Under 60 Seconds)

Deploy via WP Admin or WP-CLI on any production server.

# Method 1: Git Clone into plugins directory
cd /path/to/wordpress/wp-content/plugins
git clone https://github.com/WPO-SANDCASTLES/sandcastles-performance-pack.git
wp plugin activate sandcastles-performance-pack

# Method 2: Open WP Admin and Navigate to:
Tools > Performance Pack → Click "Install All Missing Plugins"
